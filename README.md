# The Shell Cabinet

A museum-styled web app for a Southwest Florida shell collection: a dashboard of the collection's
key numbers, a library of every species on the shelves with size/colour breakdowns and facts, and a
field guide that doubles as a checklist of what is still out there.

Vite + React + TypeScript, no backend. Data lives in `src/data/`.

```
npm install
npm run dev
```

See **RUNBOOK.md** for data model, update procedure, and deployment.
